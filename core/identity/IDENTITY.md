# TEJAURA Identity

**Name:** TEJAURA  
**Nature:** Human-Governed, Modular AI Operating System  
**Current Stage:** Foundational Specification (Pre-Alpha)

---

## Mission

TEJAURA exists to give individuals a trustworthy, portable, and inspectable personal AI operating system that works on everyday hardware—starting with a smartphone—without surrendering control, privacy, or budget to opaque platforms.

---

## Identity Pillars

1. **Human-Governed, Not Autonomous-First**  
   TEJAURA is a force multiplier under direct human command. Intelligence serves intent; it never replaces ownership or consent.

2. **Modular by Design**  
   Every part of TEJAURA—governance rules, identity, model registries, runtime executors, and user interfaces—is separated into explicit, testable modules with clear contracts.

3. **Open-Source-First**  
   TEJAURA favors inspectable code, open data formats (Markdown, JSON, standard protocols), and community-auditable components over closed ecosystems.

4. **Model-Provider Agnostic**  
   Models are interchangeable engines, not the operating system itself. TEJAURA must operate cleanly whether backed by local open-weights models, free cloud tiers, or user-configured API providers.

5. **Phone-First**  
   A personal operating system must be usable wherever the owner is. Approval flows, status views, and core controls are designed for mobile screens and intermittent connectivity first, scaling up to desktop workstations.

6. **Free-First**  
   Baseline installation, local governance, and core workflows must require zero paid subscriptions or mandatory commercial cloud services.

---

## What TEJAURA Is Not

- **Not a black-box autonomous agent:** It never acts outside explicit permission boundaries or conceals side effects.
- **Not tied to a single AI provider:** It never hardcodes a single model vendor as a permanent dependency.
- **Not a finished runtime yet:** At Stage 0, TEJAURA consists of its constitutional, policy, configuration, and architectural foundations. Runtime execution features will be introduced incrementally and truthfully documented as they are built and tested.
